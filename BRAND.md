# CEDIMS brand system

## Brand idea

CEDIMS is the shared instructional record for Calapan East District: clear, accountable, and practical for teachers and supervisors.

**Brand line:** Clear records. Shared responsibility.

## Identity

- **Name:** CEDIMS
- **Expanded name:** Calapan East District Instructional Monitoring System
- **Voice:** direct, respectful, calm, and useful
- **Audience:** teachers, Master Teachers, School Heads, and District Supervisors
- **Promise:** make instructional records easier to submit, review, verify, and act on

## Visual language

Use a quiet institutional interface. Prefer solid surfaces, thin borders, readable type, and one clear action per area. Avoid decorative gradients, glass effects, excessive rounded containers, and animation that does not communicate state.

### Color palette

| Role | Color | Use |
| --- | --- | --- |
| District navy | `#123B63` | Wordmark, headings, trust cues |
| CEDIMS blue | `#1E40AF` | Primary actions, active navigation, links |
| Education gold | `#F2B705` | Section markers, attention, progress accents |
| Alert red | `#CE1126` | Errors and critical missing records |
| Success green | `#15803D` | Confirmed and compliant states |
| Ink | `#172B3F` | Primary text |
| Muted blue-gray | `#536779` | Supporting text |
| Canvas | `#F5F7FA` | Page background |

### Typography

Use Segoe UI, Roboto, or the system sans stack. Headings use strong weight and short line lengths. Body copy should remain at 16px or larger where space allows. Use uppercase text only for short labels and status markers.

### Logo

Use the existing assets in `static/brand/`:

- `cedims-lockup-horizontal.svg` for light surfaces
- `cedims-lockup-horizontal-reverse.svg` for dark surfaces
- `cedims-wordmark.svg` for compact headers
- `cedims-lockup-stacked.svg` for narrow spaces

Keep clear space around the logo and do not recolor, stretch, rotate, or add effects to it. The district seal is a supporting identifier, not a replacement for the CEDIMS wordmark.

## UI language

Prefer action-oriented labels: **Review missing**, **Open schools**, **View archive**, **Verify document**, and **Save changes**. Keep status labels consistent: **Compliant**, **Late**, **Missing**, **Pending review**, and **Offline**.
