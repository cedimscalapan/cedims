# Smart E-VISION — Concise User Manual
**Calapan East District Instructional Monitoring System**
*Quick reference of all features per role.*

---

## Common Features (All Roles)

| Feature | How to Use |
|---|---|
| **Dashboard** | Home screen. Shows compliance rate, uploaded documents, alerts, recent activity, and a weekly compliance checklist. |
| **Calendar** | View the academic calendar: school year, term, and submission deadlines for each week. |
| **Archive** | Browse all submitted documents. Search by teacher, subject, week, or status. |
| **Settings** | Update your profile name/photo, change your password, toggle dark mode, enable voice guidance, and manage notification preferences. |
| **Scan Document** | Open the in-app QR scanner (camera) to verify any stamped document instantly. |
| **Chatbot** | Floating assistant that answers questions about compliance, deadlines, teacher stats, school comparisons, and finds DLLs. |
| **PWA Install** | Install the app on your device for offline use and a native-app experience. |
| **Offline Mode** | Work without internet — uploads are queued and auto-synced when connection returns. |

## 1. Teacher

**Navigation:** Dashboard, Upload, Teaching Load, Archive, Calendar, Settings, Scan, Chatbot.

### Features

| Feature | Description |
|---|---|
| **Upload** | Submit instructional documents (DLL, ISP, ISR) for each teaching load, week, and term. |
| **Teaching Load** | View your assigned subjects, grade levels, and weeks; see what still needs submission. |
| **Auto-Fill (OCR)** | The system automatically reads your document and pre-fills subject, grade, week, and doc type — verify before submitting. |
| **QR Stamping** | Every uploaded PDF is automatically stamped with a QR verification code. |
| **Document Status** | Track each submission: Compliant (on time), Late, Non-Compliant, or Pending review. |
| **Copilot Suggestions** | During upload, get smart tips: which week is missing, upcoming deadlines, duplicates, and subject mismatches. |
| **Review Feedback** | View comments, annotations, and outcomes from Master Teacher / School Head reviews. |
| **Archive** | Search and re-download your past submissions. |

---

## 2. Master Teacher

**Navigation:** Dashboard, Archive, Calendar, Settings, Review, Scan, Chatbot.

### Features

| Feature | Description |
|---|---|
| **Review** | Open documents pending review. Inspect the PDF, check the AI-extracted metadata (week, subject, grade, teacher, school), and leave feedback. |
| **Annotation** | Highlight text, add comments/notes, and mark critical issues directly on the document. |
| **Approve / Request Revision** | Accept a compliant document or send it back to the teacher with comments. |
| **Audit Trail** | View the full history of a submission: upload time, changes, and review decisions. |
| **School Compliance View** | Monitor compliance across teachers in your school (from Dashboard and Archive). |
| **Cluster Analytics** | See teachers grouped into performance clusters (consistently meeting, progressing, building momentum). |

---

## 3. School Head

**Navigation:** Dashboard, School Monitor, Analytics, Archive, Calendar, Settings, Scan, Chatbot.

### Features

| Feature | Description |
|---|---|
| **School Monitor** | Compliance matrix of all teachers in your school, week by week (color-coded). Click a cell for details. |
| **Analytics** | Charts and trends: submission volume, compliance rate per teacher, document quality. |
| **Predictive Alerts** | System flags teachers at risk of non-compliance for upcoming weeks. |
| **Pattern Detection** | Automatic alerts for consecutive late/missing submissions or suspicious bulk uploads. |
| **Archive** | View/download any document in your school. |
| **Heatmap** | Drill-down compliance heatmap across teachers and weeks. |

---

## 4. District Supervisor

**Navigation:** Dashboard, District Monitor, Analytics, Admin Panel, Archive, Calendar, Settings, Scan, Chatbot.

### Features

| Feature | Description |
|---|---|
| **District Monitor** | Compliance overview across all schools in the district; compare school performance. |
| **Analytics** | District-wide trends, school rankings, risk scores. |
| **Admin Panel** | Create user accounts (teachers, school heads, master teachers), assign roles, districts, and schools. |
| **User Management** | Change user roles, reset access, and manage all accounts. |
| **Calendar / Deadline Management** | Set academic terms, weeks, and submission deadlines for the whole district. |
| **Compliance Alerts** | Receive real-time notifications for district/school compliance risks. |

## Document Status Meanings

| Status | Meaning |
|---|---|
| **Compliant** | Submitted on time and accepted. |
| **Late** | Submitted after the deadline; still accepted. |
| **Non-Compliant** | Missing or not accepted. |
| **Pending** | Uploaded, awaiting review. |

## Quick Troubleshooting

| Problem | Solution |
|---|---|
| Upload stuck | Check internet; it will auto-sync from the offline queue. |
| Wrong auto-filled info | Edit the fields before submitting. |
| Forgot password | Use "Forgot password?" on the login page. |
| Offline on mobile | Ensure the app is installed (PWA) for best experience. |
